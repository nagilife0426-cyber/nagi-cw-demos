# 業務自動化・AI活用 デモ集

GAS・Python・Claude（AI）を使った業務自動化のデモ集です。
各デモはブラウザだけで動作します（すべてダミーデータ・外部送信なし）。

👉 トップページ: [`index.html`](./index.html)

## デモ一覧

| デモ | 内容 | 主な技術 |
|------|------|---------|
| [SNS自動投稿](./a1-sns-autopost/demo.html) | Instagram2＋Threads2へ150パターンを自動ループ投稿 | GAS / Graph API |
| [AI投稿文 生成・自動投稿](./a2-threads-claude/demo.html) | ClaudeでThreads投稿文を生成→承認→自動投稿 | Claude API / Python |
| [Amazonセラー集計ダッシュボード](./a3-amazon-aggregator/demo.html) | 売上・粗利・ACoS・在庫をワンクリック集計 | GAS / Excel VBA |
| [法人データ収集ツール](./a4-company-scraper/demo.html) | 企業名→郵便番号・住所・代表者名を抽出 | Python / スクレイピング |

各フォルダにデモUI（`demo.html`）・実装コード・設計ドキュメントを同梱しています。
